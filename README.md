# Unirock Cherry LPS

Unirock Cherry LPS is a clean-DI, physically modelled dual-humbucker electric-guitar instrument for Windows VST3 and Standalone.

![Unirock Cherry LPS interface](imgs/interface_screenshot.png)

## Installation

Run `Pro2Max_Unirock_Cherry_LPS_Setup_1.0.0.exe` and select a folder for the sample library when prompted. The installer records that location for both the VST3 and Standalone editions, so the library can live on any drive.

## Use

- Load the VST3 in a 64-bit Windows DAW, or launch the included Standalone application.
- Select pickup position with keyswitches: C-1 Bridge, C#-1 Both, D-1 Neck.
- Select articulations with C0-G#0. Pick scrapes use F#-1 (short) and G-1 (long).
- The Settings panel contains output trim, Auto Sustain, articulation controls, and MIDI pitch-bend range.

The hybrid sample library is used where its rendered state matches the performance. Dynamic playing, alternate pickup states, note releases, pitch bend, slides, and unavailable sample variations remain on the physical engine.

## Requirements

Windows 10 or later, 64-bit VST3 host, and at least 1.5 GB of free space for the sample library.
